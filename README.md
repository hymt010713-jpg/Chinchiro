# チンチロ五

五面チンチロ（2〜6人）。オンライン対戦と、1台の端末を回して遊ぶ版がある。

設計書: https://claude.ai/artifact/6crGxYSSQCns3YHG8bbso1

## 遊ぶ（同じWi-Fiの仲間と）

```bash
npm install
npm start        # 画面をビルドしてサーバーを起動
```

起動すると `同じWi-Fiの端末から: http://192.168.x.x:8787` と表示される。そのURLを各自のスマホで開き、1人が「部屋を作る」→ 招待リンクか4文字の部屋番号を送る → 他の人が入る → 部屋主が開始。

1人で試すときは BOT を入れられる:

```bash
cd apps/server
npx tsx scripts/bots.ts ABCD 2       # 部屋 ABCD に BOT を2人
npx tsx scripts/bots.ts --create 3   # BOT 3人だけで1局通す
```

## インターネットに公開（Render）

`render.yaml` があるので、Render の Blueprint でそのまま公開できる。

1. https://render.com に GitHub アカウントでログイン
2. 「New +」→「Blueprint」→ このリポジトリを選んで「Apply」
3. 数分でビルドが終わり、`https://chinchiro-go-xxxx.onrender.com` のようなURLで遊べる

`main` に push するたびに自動で更新される。無料プランは15分アクセスがないと眠り、次に開いたときの起動に1分ほどかかる。部屋はメモリに置いているので、更新や再起動で消える。

## 開発

```bash
npm run dev:server   # ゲームサーバー（:8787、変更で再起動）
npm run dev          # 画面（:5173、/ws はサーバーへ転送）
npm test             # 役判定・精算・進行・部屋のテスト
npm run typecheck
```

## 構成

| 場所 | 中身 |
| --- | --- |
| `packages/rules` | 役判定（`judge`）、勝負（`settle`）、1卓の進行（`createGame` → `placeBet` → `closeBets` → `rollFor` → `nextRound`）、通信の型と演出の時間（`protocol.ts`）。サーバーと画面の両方が使う |
| `apps/server` | Node + `ws`。部屋（`room.ts`）が出目・締切・演出待ちを決める。静的ファイルも配信するので1つのURLで遊べる |
| `apps/web` | 画面（Vite + React）。対局画面（`Table.tsx`）は1台版とオンライン版で共通。効果音は `src/lib/sfx.ts` の Web Audio 合成 |

## オンライン対戦の決まりごと

- 出目はサーバーが暗号学的乱数で決める。画面は演出するだけ
- 賭け15秒・投擲10秒。過ぎたらサーバーが1口で決定／自動で振る
- 接続が切れても席は残る（同じタブで開き直せば戻れる）。対局中はBOTが代わりに打つ
- 誰かの投擲の演出中は次の人は振れない（演出の長さはサーバーと画面で共有）
- 「退室」を押したときだけ席を空ける。再戦のときは接続が切れたままの人を外す

## ルール（確定分）

- 子は1〜5口（1口＝100点）。子が親の左隣から時計回りに振り、親が最後に1回振る
- 強さが上の方が勝ち。同じ役どうし・同じ目は親の勝ち。引き分けなし
- 四ゾロ ＞ ピンゾロ ＞ 順新滝 ＞ 嵐。四ゾロ・ピンゾロ・順新滝はすべて勝ち倍率5倍だが、強さは異なる
- 支払い＝口数 × 勝った側の倍率 × 負けた側の払い倍率
- 親は時計回りに交代し、全員が同じ回数だけ親をやったら終局。周数は3〜10周（局数＝人数×周数）
- 新滝（任意）: 23456＝順新滝 5倍、12345＝逆新滝 5倍払い
- ションベン（任意）: 投げるたびに1%。最弱・1倍払い

### 名前による出目の補正

通常の対局でも、参加者名が「ひろきちくん」「ひろきち」「新滝」のいずれかに完全一致すると、本人の投擲に次の補正を適用する（オンライン・1台版共通、親子とも対象）。別のモードやアカウント権限は不要。

- ヒフミ：通常確率の1/2
- 逆新滝：通常確率の1/3（新滝ルールON時のみ）
- 嵐・四ゾロ：それぞれ通常確率の1.5倍
- 増減分は通常の「目」から差し引く。4・5・6の目の比率は維持する
- その他の役、ションベンの確率、役の強さ、支払い倍率、最初の親決めは変更しない

名前の前後の空白は既存の入室処理で除去される。別表記（「新瀧」など）や名前への文字追加は対象外。同じ名前の重複入室は、これまでどおり不可。

### 四面・五面の演出と振動

- 四ゾロ・四ピン：役が確定したタイミングで連続振動。
- 五ゾロ・五ピン：専用の長めの振動、金色の光・紙吹雪・役名の大きな表示、専用の効果音。
- 対局画面の「振動あり／振動なし」で端末ごとに切り替え。設定は保存され、音のON／OFFとは独立。
- オンラインでは、その投擲を見ている各端末で演出する。名前による確率補正の対象者に限らず、全員の四面・五面が対象。
- 振動は対応端末・ブラウザのみ。iPhoneのSafariなど非対応環境では「振動非対応」と表示し、画面・音の演出を使う。実際の振動にはページ操作と端末側の振動設定が必要。
- 端末の「視差効果を減らす」等に従い、動きを抑えた表示にも対応。演出時間・役の強さ・得点計算は変更しない。
